# 导演手记

## 画面从哪来

路由器片里，一个小动作就能启动整套原理演示。红球压向水面，涟漪离开发射处，镜头追到接收端；当观众要比较振幅和频率时，镜头回到正视，几条波形共享输入和时间轴。《可控代码生成视频》汇报里最值得保留的做法，是把场景、状态和时间分开，观众指出某秒，制作者就能改那一处。像素街景是那个项目的 MV 案例，科普片的视觉标尺取自路由器终版。

| 画面选择 | 构图与动作 | 使用时机 |
|---|---|---|
| 立体实验台 | 奶油色环境、青绿主体、哑光物件、接触阴影。物体要有体积、支点与去向。跟拍真正移动的主角，由细节拉远揭出系统。 | 开场、空间关系、发送到接收、可操作的生活类比 |
| 原理对照板 | 米白画布、墨绿标注、共用坐标、同步游标。两次实验只改一个量；成功、缺口、误差写明含义，也可用线型或形状区分。 | 要观众判断差异时，例如同一串比特上的三种波形 |
| 混合 | 把实验台上的同一对象移到正视图，沿用相同位置关系、颜色和编号。对照结束，回到开场的问题。 | 一集里既需要直觉，又需要严谨解释时 |

从终版原理图采样的基色为米白 `#F1ECD9`、墨绿 `#184142`、青绿 `#158480`、砖红 `#CB4E34`，少量赭黄 `#BF891F`。字幕在安全区直接排字。让背景在这里平静下来。左上角留给场景；章节导航放底边，可关闭。横摇、升降、拉远、绕行由旁白动作触发，对比镜头锁定机位与比例。快动作后留出能读出结果的一拍。在落水、扣合、抵达等动作点加入短声，旁白保持清楚；最有解释力的声音有时是刻意留出的安静。

## 哪一句之后该安静

如果下一句会提前说出观众正在等的结果，把它放到动作落定之后。写旁白时就在完整的语义停顿处给画面留位置。比如说完“把缺失部分补回来”，镜头先对准空槽，跟着补传块入槽。滑动声随位移，短扣合声对准接触的第一帧，音乐和旁白让出这一下。停住仍可看见的结果，让观众读出“1–300 已连续到达”，再接重复段的讲解。物件无需强调时可只留画面和人声。

章间换视角时，选一个上一镜已有、下一镜还用得上的对象。由立体实验台转为平面图，就让同一块数据保持位置，台面和阴影逐渐退去，序号始终可辨。需要定位时移动镜头，需要比较时停稳镜头。回看时戴耳机听落点，再静音看一遍，确认观众能指出哪里发生了变化。

## 同一个事实，三种讲法

- **生活追问**。「给同事传文件，中间少了一截，最后一截倒先到了。现在能把后半截交给软件吗？」镜头跟随后到的字节，停在接收缓冲区。
- **课堂推演**。「把 1 到 300 分成三段。先送第一段和第三段，猜一猜，应用现在能顺序读到哪里？」先让观众作判断，再补中段揭晓。
- **技术拆解**。「101 到 200 还没到。接收端可以缓存 201 到 300，交付位置仍停在缺口前。」并排显示缓冲区和已交付字节。

写稿把例子贯穿到底。每次类比要说清它解释哪一个关系，在比例、尺度或物理传播方式容易混淆处回到真实模型。新一章接住上一章留下的问题。视觉口味、解说口吻、配音角色三项分别选择，高中数学女老师也可以讲生活追问。

## 可复用的 SVG 动作

Remotion Studio 中打开 `SvgMotions` 可看三个镜头。导出预览可运行 `npx remotion render src/index.tsx SvgMotions renders/svg-motions.mp4`。正式成片使用下列已注册的 scene 名称，在当前工程的 `script/narration.json` 给相应节拍填写 scene、text、action 等字段，按配音流程重建时间轴。每个示例镜头在一个节拍内完成。

| 分镜 scene | 可观察的变化 | 迁移到其他主题 |
|---|---|---|
| `dns-relay` | 请求到达解析器，显示缓存命中，返回地址后电脑亮起。 | 用 `TraceRoute` 传入按行进顺序排列的折线顶点和进度。进度按真实线长分配，到达顶点时点亮。负进度可让返程在请求到达前保持待机。 |
| `packet-layers` | 以太网帧的载荷原位展开为 IPv4 数据报，再定位到 TCP 报文段。停稳后，引线和层名依次显现。 | 用 `ExplodedLayers` 提供每层的图形、名称、引线锚点及层距。让子结构与上一层承载它的区域对齐，观众可沿同一列追踪对象。 |
| `tcp-compare` | 同一批字节按同一节奏发送。下方第二段首次丢失，可交付量停在 100 字节。补传抵达时变为 300。 | `ComparePair` 将同一进度送入两次相同的绘图函数。两行共用尺度和输入序列，只改要解释的条件。把当前结果直接标在行尾。 |

这些组件由本拍的 `motion` 驱动，取值从 0 到 1。需要精确落音时，在分镜上设置 `landing`，让进度在 `landAt` 帧达到 1。TCP 对照镜头会在旁白期间建立缺口，只有补传块的位移使用 `motionFrom` 到 `landAt` 的落音窗口。DNS 和分层示例将整段动作放在给定的运动窗口内，给往返和逐层辨认留足时间。一次讲解里若请求、等待和应答各自占一句，应在各拍延续上一拍的状态。范例连续演示的起动、停稳和拟音可在 [Showcase.tsx](../assets/starter/src/svg/Showcase.tsx) 中查看。组件接口在 [Motions.tsx](../assets/starter/src/svg/Motions.tsx)，三个参考镜头在 [NetworkScenes.tsx](../assets/starter/src/svg/NetworkScenes.tsx)。

DNS 示意采用解析器缓存命中的情形。封装图采用以太网承载 IPv4、IPv4 承载 TCP 的例子。TCP 图采用相对字节编号，统计可按序交付的连续前缀。[DNS 解析器与缓存](https://www.rfc-editor.org/rfc/rfc1034) · [以太网承载 IP](https://www.rfc-editor.org/rfc/rfc894) · [TCP 字节序列](https://www.rfc-editor.org/rfc/rfc9293)
